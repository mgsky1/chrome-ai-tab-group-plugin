# 隐私政策

## 概述
本隐私政策适用于 AI 自动标签页分组 Chrome 浏览器插件 Ai-tab（以下简称“本插件”）。本插件旨在通过分析用户打开的标签页内容，利用大模型为用户提供智能的标签页分组建议。我们非常重视用户的隐私保护，本政策将详细说明我们如何收集、使用、存储和保护您的信息。

## 信息收集与使用

### 1. 收集的信息类型
本插件会收集以下两类信息以实现其核心功能：

- **网页内容信息**：当您使用本插件时，我们会临时收集您当前打开的标签页的**部分可见文本内容**（例如网页标题、正文摘要等）。这些信息仅用于发送至您指定的大模型服务商（如 DeepSeek、OpenRouter 等）的 API，以生成标签分组建议。
    - **重要说明**：我们**不会**收集您浏览的完整网页内容、历史记录、密码、 cookie、表单数据等敏感个人信息。
- **API 密钥信息**：为了调用大模型服务，本插件需要您提供相应服务商（如 DeepSeek、OpenRouter）的 **API Key**。此密钥由您在插件设置中手动输入。

### 2. 信息的使用方式
- **网页内容**：收集的网页内容片段将**仅作为提示词（Prompt）的一部分**，通过您提供的 API Key，发送给您选择的大模型服务商，以请求生成分组标签。**我们不会将此内容用于任何其他目的，也不会将其发送给除您指定的大模型服务商之外的任何第三方。**
- **API 密钥**：您提供的 API Key **仅存储在您本地设备的 Chrome 浏览器存储空间（如 `chrome.storage.local`）中**。该密钥**永远不会发送到我们的服务器或任何其他第三方服务器**。所有调用大模型 API 的请求均直接从您的浏览器发生到相应服务商。

## 数据存储与安全

### 1. 存储位置与方式
- **本地存储**：所有数据，包括您配置的 API Key，均**仅加密存储在您的本地设备上**。我们没有任何中央服务器来收集或存储这些信息。
- **临时处理**：从网页提取的文本内容仅在内存中临时处理，用于构造 API 请求，**不会被持久化保存在本地或任何服务器上**。一旦请求完成，这些临时数据将从内存中清除。

### 2. 数据安全
- 我们依靠 Chrome 扩展程序沙箱环境和 `chrome.storage.local` API 的安全机制来保护本地存储的数据。
- 请妥善保管您的大模型服务商账户和 API Key，并遵循其服务条款与安全建议。您有责任管理您 API Key 的用量和权限。

## 数据传输
- **至大模型服务商**：网页内容片段和必要的 API 参数会通过 HTTPS 加密连接直接发送到您配置的大模型服务商 API 端点。
- **无其他传输**：我们**不会**将您的 API Key、网页内容或生成的标签数据发送到除您指定的大模型服务商之外的任何其他服务器。

## 用户权利与控制
- **完全控制**：您随时可以在插件设置中查看、修改或删除您存储的 API Key。
- **功能启停**：您可以通过禁用或卸载本插件来完全停止所有数据收集与处理活动。
- **数据访问**：由于我们不在外部服务器存储任何您的个人数据，因此不存在向我们请求数据副本或删除的场景。所有数据均在您的设备本地。

## 第三方服务
本插件的智能分组功能依赖于您选择的大模型服务商（如 OpenAI）。当您使用其 API 时，您提供的内容将受该第三方服务商的隐私政策和服务条款约束。我们强烈建议您阅读并理解这些政策。

## 政策变更
我们可能会不时更新本隐私政策。任何重大变更都会通过插件更新通知或在相关页面发布更新后的政策。您继续使用本插件即表示接受更新后的政策。
